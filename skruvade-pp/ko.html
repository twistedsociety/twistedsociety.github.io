요약: 앱은 여러분에 관한 어떤 데이터도 수집하지 않아요. 전혀요.

앱이 수집하는 정보

없어요. 앱에는 계정, 분석 도구, 광고, 추적, 제3자 코드가 없어요. 누가 플레이하는지, 무엇을 얼마나 자주 하는지 저희는 절대 알 수 없어요.

휴대폰에 남는 정보

플레이어 이름, 설정, 직접 만든 덱, 이미 한 카드는 기기에만 저장되어 다음에도 게임이 기억해요. 앱을 삭제하면 함께 삭제돼요.

여러 휴대폰으로 플레이할 때

친구들이 자기 iPhone으로 참여하면 휴대폰끼리 로컬 네트워크로 직접 통신하고, 서버를 거치지 않아요. 호스트의 휴대폰은 각 게스트의 이름, 진행 동작, 그리고 연결이 끊긴 휴대폰이 다시 들어올 수 있게 하는 무작위 ID를 받아요. iOS는 이 기능을 사용할 때만 로컬 네트워크 접근 권한을 요청해요.

이 웹사이트

이 사이트는 쿠키, 분석 도구, 광고를 사용하지 않아요. 호스팅은 GitHub이 맡고 있으며, 다른 웹 호스팅 업체처럼 페이지를 보여 주고 안전하게 유지하기 위해 IP 주소 같은 기술 데이터를 처리해요. 저희는 그 데이터에 접근하거나 사용하지 않아요.

어린이

이 게임은 모든 연령을 위해 만들었고, 어린이를 포함해 누구에게서도 데이터를 수집하지 않아요.

변경 사항

앱의 데이터 처리 방식을 바꾸게 되면 이 페이지를 먼저 업데이트할게요.
